# Background music

Drop royalty-free `.mp3` files in this folder. They appear as selectable tracks
in the web UI and can be chosen on the CLI with `--bgm-name <file.mp3>`.

Make sure any music you add is licensed for your intended use (e.g. from
sources like the YouTube Audio Library, Pixabay Music, or Free Music Archive).
These files are intentionally **not** committed to the repo.
